# 🌐 Projeto de Webapp – Currículo Interativo

Este repositório foi criado para a entrega da atividade da **Unidade I da disciplina de Webapps**. O objetivo do projeto foi desenvolver uma página web estática e interativa para apresentar meu currículo profissional e acadêmico.

A página foi construída do zero utilizando **HTML5** para a estruturação semântica, **CSS3** para a estilização responsiva e visual, e **JavaScript** básico para adicionar interatividade ao usuário. O projeto também conta com a organização de mídias e arquivos em pastas estruturadas.

---

## 📂 Conteúdo do Repositório

* **`index.html`**: Estrutura semântica principal da página do currículo.
* **`style.css`**: Folha de estilos com layout flexível (Flexbox), cores e responsividade.
* **`script.js`**: Funcionalidades e interações com o usuário via JavaScript.
* **`/media/`**: Imagens e recursos visuais utilizados na página.
